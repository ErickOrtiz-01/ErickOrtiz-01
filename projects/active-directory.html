SYS.01
MODULE 01

Virtualization infrastructure

Deployed a bare-metal Proxmox host on repurposed hardware. Created DC01 running Windows Server 2022 and CLIENT01 running Windows 11 Pro. Installed VirtIO drivers to support virtual storage and networking.

SYS.02
MODULE 02

Domain services and DNS

Configured DC01 with static IPv4 address 192.168.50.20, installed Active Directory Domain Services and DNS, and promoted the server to the corp.ortizlabs.com forest (NetBIOS: CORP).

SYS.03
MODULE 03

Organizational structure and identities

Created the Ortiz Labs OU hierarchy with Employees, Computers, Groups, Service Accounts and Disabled Accounts. Employees contains IT, Human Resources, Finance, Sales and Management. Computers contains Workstations and Servers. Groups contains Security Groups and Distribution Groups. Provisioned ten fictional employee accounts across five departments.

SYS.04
MODULE 04

Group Policy and security

Configured password length of 14 characters, history of 24 passwords, minimum age of one day, complexity enabled and no periodic expiration. Configured a five-attempt lockout threshold with a 15-minute lockout. Restricted Control Panel access for employees while exempting help desk agents. Configured a corporate logon banner and a 600-second workstation inactivity lock.

SYS.05
MODULE 05

Domain workstation and remote administration

Joined CLIENT01 to the CORP domain and installed Remote Server Administration Tools (RSAT). Used a non-administrator help desk account to perform delegated directory operations remotely rather than relying on Domain Admin privileges.

Add-WindowsCapability -Online -Name Rsat.ActiveDirectory.DS-LDS.Tools~~~~0.0.1.0
SYS.06
MODULE 06

Delegated help desk operations

Delegated password reset and account unlock capabilities to GG_Helpdesk_Agents at the Employees OU. Tested password reset and account unlock against the fictional Peter Parker account from CLIENT01.

SYS.07
MODULE 07

Troubleshooting: access denied

During initial testing, Tony Stark received Access is denied when attempting to reset Peter Parker’s password. Verified the help desk security group in the current access token and inspected inherited permissions on the target user. The inspected permission entry did not include Reset password. Reapplied the password-reset delegation at the Employees OU and successfully retested the operation. Account unlocking was also validated.

Original error screenshot was not retained; the evidence below documents the corrected configuration rather than recreating the failure.

SYS.08
MODULE 08

Validation and results

Validated password reset, account unlocking, standard employee Control Panel restrictions, help desk exemption, corporate logon banner and automatic workstation locking. All of these functional checks passed.
